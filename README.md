# river-levels

## Getting Started

```sh
yarn install
npx projen build
```

## CDK

On first run of a CDK installation:

```sh
npx cdk bootstrap
```

Build the project
```sh
npx projen build
```

Deploy the CDK stack
```sh
npx projen deploy
```
